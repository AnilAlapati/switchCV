## 🔑 Key Interactions

### Accept Button Flow
```
User clicks "✓ ACCEPT RESUME"
         ↓
setIsReviewLoading(true)
         ↓
buildResumeProfile()
    ├─ Merge AI content with user data
    ├─ Create database record
    └─ Generate numericId/slug
         ↓
saveResumeToDB()
    ├─ Save to Firestore
    ├─ Create index entry
    └─ Generate share URL
         ↓
Show Success Message + URL
         ↓
User can copy & share link
```

### Rewrite Button Flow
```
User clicks "✎ REQUEST REWRITE"
         ↓
showFeedback = true
         ↓
User types feedback:
  - "Add more achievements"
  - "Make it more concise"
  - "Highlight leadership"
         ↓
User clicks "Generate New Version"
         ↓
retryCount++
feedbackContext = user's feedback
         ↓
handleResumeGeneration(feedback)
    ├─ Add feedback to LLM prompt
    ├─ Generate new content
    ├─ Show in modal again
    └─ Ready for accept/rewrite
         ↓
Repeat up to 5 times
```
