HOW TO USE
================================================================================

FOR RECRUITERS:
  1. Visit http://localhost:3000/dashboard
  2. Scroll to "Profile Settings" card
  3. Toggle "Recruiter Account" ON
  4. Enter company name and save
  5. Scroll to "Recruiter Resume Search"
  6. Search for candidates by number/name/skill
  7. Click "View Resume" or "Request Access"

FOR DEVELOPERS:
  1. Review DASHBOARD_RECRUITER_FEATURES.md for API docs
  2. Check IMPLEMENTATION_SUMMARY_DASHBOARD_RECRUITER.md for details
  3. Run: npm run build (verify compilation)
  4. Run: npm test (verify tests pass)
  5. Run: npm run dev (test locally)
